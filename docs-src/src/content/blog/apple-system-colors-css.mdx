Apple's colors are pairs, not values. Each one has a light appearance and a dark appearance, and the dark one is a little brighter on purpose. Every table below gives both, with the Puppertino custom property that holds them. Load one stylesheet and use the property; the pair flips with the system.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@codedgar/puppertino@2.0.0/dist/css/colors.css">
```

```css
.badge { background: var(--p-sys-blue); color: #fff; }
```

Put `p-auto-dark-mode` on the body to follow the system, or `p-dark-mode` to force dark.

## The control accent

Blue is also the accent for every tinted control: filled buttons, switches, sliders, progress bars and the selected segment. It is the same blue as links and selection.

| Token | Light | Dark | What it is |
|---|---|---|---|
| `--p-control-accent` | `#0088FF` | `#0091FF` | The default control fill |
| `--p-control-accent-text` | `#0078F0` | `#0091FF` | The accent as text on a material |
| `--p-focus-ring` | `rgba(0,136,255,0.5)`, 3.5px outside plus 1px inside | Same at `rgba(0,145,255,0.5)` | Keyboard focus on fields and controls |

A browser cannot read the accent a person chose in System Settings. Apple's own apps use blue when no accent is set, so default to blue and let a class change it per control.

```css
.my-field:focus-visible {
  outline: none;
  box-shadow: var(--p-focus-ring);
}
```

Six levels. Primary is not pure black: Apple uses 85 percent so the surface shows through, which matters over glass.

| `--p-separator-opaque` | `#C6C6C8` | `#38383A` |

Draw hairlines with an inset box shadow of half a pixel, so they stay one device pixel on a retina screen.

```css
.row { box-shadow: inset 0 -0.5px 0 var(--p-separator); }
```

## Three rules that keep it looking right

- **Use the pair.** A light value on a dark background looks dull, and a dark value on white looks garish. The token does this for you; a pasted hex does not.
- **Color is never the only signal.** Pair red with the word Delete, green with a checkmark. Apple does, and so do the people who cannot tell them apart.
- **Red is for destruction.** One accent for brand or selection, red for the action that cannot be undone, and nothing else gets red.
