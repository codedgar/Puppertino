A dialog presents a scoped task in its own window, like saving a document. A sheet presents the same kind of task attached to the top of its parent context. Both share one surface: an opaque background, a 26px radius, and a deep shadow with a 1px edge ring. For short confirmations, use [alerts](/docs/desktop/modals/) instead.

## Anatomy

The window is 390px wide by default, padded 20px. The title is 13px bold. The message is 11px with a 14px line height. Form rows use a two-column grid: right-aligned 13px labels in the secondary text color, then the control. Rows sit on a 30px rhythm (24px controls with 6px gaps).

| Class | Role |
|---|---|
| `.p-dialog` | The window surface. Radius 26, 20px padding, shadow plus 1px ring. |
| `.p-dialog__title` | 13px bold heading. |
| `.p-dialog__message` | 11px supporting copy. |
| `.p-dialog__form` | Two-column grid of labels and controls. |
| `.p-dialog__label` | Right-aligned row label, secondary color. |
| `.p-dialog__footer` | Action row, right-aligned. |
| `.p-dialog__footer-leading` | Pushes one action (usually destructive) to the left edge. |
| `.p-sheet` | The same surface presented from the top of a host. |
| `.p-sheet-host` | Positioning context for an attached sheet. |

Fields, selects, and buttons inside a dialog are the standard [form controls](/docs/desktop/forms/) and [buttons](/docs/desktop/buttons/). Nothing is restyled.

## Footer layout

Place the destructive action on the leading edge with `.p-dialog__footer-leading`, and end with Cancel then the primary action. This mirrors the order people expect on macOS: destruction far from confirmation.

```html
<div class="p-dialog__footer">
  <button class="p-button p-button-destructive p-dialog__footer-leading">Delete</button>
  <button class="p-button p-button-secondary" data-p-cancel>Cancel</button>
  <button class="p-button p-button-primary">Save</button>
</div>
```

## Opening a dialog

Dialogs run through the same modal manager as alerts. Add `.p-modal` next to `.p-dialog`, put it inside `.p-modal-background`, and open it with `data-p-open-modal`.

## Sheets

A sheet is the same surface sliding down from the top of its host. Inside a `.p-sheet-host` it attaches to that container. Inside `.p-modal-background` it attaches to the viewport. The entrance uses the 0.35s sheet timing.

## Dark mode

The surface swaps to the elevated dark background (`#2C2C2E`), the ring lightens to 10% white, and shadows soften to about 70% of their light values. Titles and copy follow the dialog text tokens. Controls inside adapt on their own.

## Accessibility

Dialogs and sheets are modal: `role="dialog"` with `aria-modal="true"`, labelled by their title. The modal manager traps focus, closes on Escape, and returns focus to the trigger. With reduced motion, the scale and slide transitions reduce to fades. The surface is opaque in both appearances, so text contrast does not depend on the backdrop.
